Comandos Essenciais

git init

Iniciar um novo repositório Git

git add .

Adicionar todas as alterações no diretório atual

git commit -m

Usado para salvar alterações, podendo inserir uma mensagem

git push -u origin main

Envia alterações do repositório local para um repositório remoto

git fetch

Verifica se o repositório remoto tem modificações em relação ao local

git pull

Puxar as mudanças do repositório

git clone

usado para copiar um repositório remoto para o seu computador local

git remote add origin

Conecta o repositório local ao repositório remoto
