Comandos Essenciais

git init

Iniciar um novo repositório Git

git add .

Adicionar todas as alterações no diretório atual

git commit -m "[Mensagem de Commit]"

Usado para salvar alterações no repositório local, podendo inserir uma mensagem para descrever um projeto

git push -u origin main

Envia alterações do repositório local para um repositório remoto
